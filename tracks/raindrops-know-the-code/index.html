About

「雨粒はコードを知っている」は、映画『マトリックス』の“赤を選ぶか、青を選ぶか”という問いを、別れた相手を忘れるか忘れないかという単純な二択ではなく、痛みのない思い出の中にとどまるのか、それとも失恋で見失っていた自分を引き受けて先へ進むのかという、もっと静かで個人的な選択として描いた曲です。窓を滑る雨を、都市を動かす見えないコードのように見つめながら、主人公は「大丈夫」と言い聞かせていた頃の自分や、愛されるために小さくしていた輪郭に気づいていきます。タイトルの雨粒は、誰かが決めた世界の規則を知っているようにも見えるけれど、涙がどこへ流れ、何を終わらせ、どんな明日を育てるかまでは決められないものとして置きました。別れを相手への恨みや敗北にせず、「戻れないこと」を悲しみながらも「戻らないこと」を自分で選ぶための合図として受け取ることで、失恋のあとに残る空白を、新しい自分の人生が始まる余白へ変えていく曲です。
