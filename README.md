# SAY-SHOW

映画のシーンから生まれる、AIコラボの音楽プロジェクト。

## 🎬 SAY-SHOW について

映画からインスパイアされたテーマを起点に、AIとアイデアをキャッチボールしながら、歌詞やサウンド、ボーカルを形にしています。

J-POPとシティポップ、インディポップをベースにした、映画インスパイア型の音楽プロジェクトです。

## 📱 サイト機能

### トップページ
最新曲を大きく 1 曲（ジャケット・曲名・60秒プレビュー・配信リンク）。その下の「SAY-SHOW をフォロー」から各配信サービスのアーティストページへ移動できます（フッターにも同じリンクがあります）。公開予定の曲があるときは、その下に「m月d日 公開予定」のカードが出ます（公開予定が複数あるときは、いちばん近い 1 曲）。

その下に、これまでの曲をジャケットのギャラリーとして新しい順に並べています。見出しの「時系列で」や、その下の「2025年10月から毎週金曜に。これまで N 週で M 曲」から History へ移動できます。

➜ [SAY-SHOW](https://say-show.me/)

### History
リリースの記録。月ごとに、日付・番号・ジャケット・曲名・インスパイア元の映画を 1 行ずつ並べています。毎週金曜のリリースがどう積み重なってきたかを、上から順に追えます。

➜ [History](https://say-show.me/history/)

### Movies
楽曲のインスパイア元になった映画のインデックス。**年代順**と**五十音順**を切り替えて、作品から曲をたどれます。カードは映画ポスターで、マウスを乗せると曲のジャケットに変わります。選ぶとその曲の詳細ページへ移動します。

➜ [Movies](https://say-show.me/movies/)

### Genres
楽曲をジャンル別に並べた索引。10 の棚に分かれ、ページ先頭の目次から目当てのジャンルへ飛べます。各棚には、そのジャンルの曲に加えて「近い音」の曲も並びます。

➜ [Genres](https://say-show.me/genres/)

### About
プロジェクトのコンセプト、映画から曲を作る流れ、AI とどう作っているか、ロゴの意味について紹介しています。

➜ [About](https://say-show.me/about/)

### RSS
新曲の公開を RSS で受け取れます。RSS リーダーや自動化サービス（IFTTT など）に登録してご利用ください。

➜ [feed.xml](https://say-show.me/feed.xml)

### 各曲の詳細ページ
左にカバーアート、右に以下の情報を上から順に掲載しています：

- 🕐 リリース日・曲の長さ・インスパイア元の映画（映画名を選ぶと **Inspired by** へ移動します）
- 🎧 **60秒プレビュー** — 自前のプレイヤー（配信前後を問わず表示）
- 🎵 **フルで聴く** — 配信サービスへのリンク（Spotify / Apple Music / Amazon Music / YouTube Music）。公開前は「配信リンクは公開日に表示されます」の案内
- 📝 **About** — 曲の背景とストーリー
- 🎚️ **Sound** — ジャンル・テンポ（BPM）・編成・雰囲気。ジャンルのタグから [Genres](https://say-show.me/genres/) の該当の棚へ移動できます
- 🎤 **Lyrics** — 歌詞
- 🎬 **Watch** — Lyrics Video 等の関連動画（該当がある場合。YouTube で開きます）
- 🎞️ **Inspired by** — インスパイア元になった映画のポスターと公開年。[Movies](https://say-show.me/movies/) へ移動して、他の映画から曲をたどれます
- 🔗 **同じ棚の曲 / 前後のリリース** — ページ最下部。近い曲へたどれます

フッターの「QR」からそのページの QR コードを表示できます。
